# Tópicos Selectos de Tecnologías Web y Móvil

Repositorio de trabajo de **José Antonio Medina Ayala** (22121289) para la materia *Tópicos Selectos de Tecnologías Web y Móvil*, Instituto Tecnológico de Morelia.

Material de referencia de la materia: <https://ealcaraz85.github.io/topicoswebmobil/#actividades>

## De qué trata el repositorio

La materia gira en torno a los **patrones de diseño de software**

Este repositorio contiene únicamente entregas individuales. El repositorio de equipo para la entrega del proyecto final recomendador de rutas es https://github.com/Cesaredmyt/proyectoEntregaTopicos/
