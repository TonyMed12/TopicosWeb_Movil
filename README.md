## Dónde encontrar cada actividad

| Actividad de la página | Qué se entrega | Dónde buscarla |
|---|---|---|
| Misiones: patrones de software para aplicaciones web (8 misiones) | Entrega escrita con las respuestas a las misiones | Raíz o carpeta de misiones del repositorio (la página no fija ruta) |
| Retos sobre la ruta de Django | `EXTRA.md` con evidencias y respuestas de los 5 retos | `EXTRA.md` en la raíz del repositorio |
| Actividades de análisis con el dataset (IA recomendador de transporte) | Código de cada actividad y `ANALISIS.md` (predicción, resultado, comparación y respuesta) | `actividades/analisis-dataset/` |
| Monolito con API frente a microservicios | Archivo con 5 secciones | `actividades/arquitectura/<matrícula>_<apellido>.md` |
| Microservicios con Docker (código) | Gateway, pedidos y recomendar, listo para `docker compose up --build` y pedido desde el puerto 8080 | `microservicios-entregas/` |
| Microservicios con Docker (informe) | Informe de 9 secciones | `actividades/microservicios-docker/<matrícula>_<apellido>.md` |
| Dataset para un asistente con recuperación (RAG) | Secciones A1 a A6 con nombre, matrícula y dominio asignado | `actividades/rag_corpus/<matrícula>_<apellido>.md` |
| Cinco días (sin clase), días 1 a 5 | Código que arranca, README de una página y notas diarias | Notas diarias en `notas/`; el resto según indique cada carpeta |
| Proyecto Flutter 1: datos y recomendador | Backend, Flutter, instrucciones, datos de prueba, capturas y análisis de patrones | Según indique el repositorio del proyecto (la página no fija ruta) |
| Proyecto Flutter 2: asistente para el comprador | Código, dataset, script de entrenamiento, modelo, capturas y análisis | Según indique el repositorio del proyecto (la página no fija ruta) |
| Proyecto Flutter 3: integración web y móvil | Repositorio, diagrama de arquitectura, demostración, informes y video de respaldo | Según indique el repositorio del proyecto (la página no fija ruta) |
